# Linguagem de Programação I (LP1)

Este repositório contém os exercícios e projetos desenvolvidos durante a disciplina de **Linguagem de Programação I** do curso de **Bacharelado em Tecnologia da Informação (BTI)** na **UFRN** (Semestre 2026.1).

## Estrutura do Repositório

O projeto está organizado por pastas representando as aulas ou temas abordados:

* **Aula 00_Termometro:** Exercícios de nivelamento.

## Pré-requisitos

Para compilar e rodar os códigos, você precisará de:

1.  Um compilador de C (Recomendado: **GCC** via MSYS2 no Windows ou nativo no Linux/macOS).
2.  Um editor de código (Recomendado: **VS Code**).

## Como Rodar os Códigos

Existem duas formas principais de executar os programas deste repositório:

### 1. Via Terminal (Recomendado)
Para testar qualquer exercício, navegue até a pasta correspondente e utilize o GCC para compilar.
**Exemplo (Exercícios da Lista Termômetro):**

```bash
# 1. Entrar na pasta da lista
cd "Aula 00_Termometro"

# 2. Compile o arquivo desejado (Ex: Fatorial)
gcc fatorial.c -o fatorial.exe

# 3. Execute o programa gerado
./fatorial.exe
```

### 2. Via VS Code (Code Runner)
Caso utilize a extensão Code Runner:

1. Abra o arquivo .c.
2. Pressione Ctrl + Alt + N (ou o botão de Play no canto superior direito).
3. O resultado aparecerá diretamente no terminal integrado.
